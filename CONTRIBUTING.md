# Contribuir / Contributing

Sugestões e correções são bem-vindas.

1. Abre uma issue a descrever o problema ou a ideia antes de um pull request grande.
2. Mantém o estilo do código: sem comentários no código, nomes claros, `./vendor/bin/pint` antes de submeter.
3. Acrescenta ou atualiza testes em `tests/Feature` e corre `php artisan test`.
4. A API tem de continuar compatível com o Snipe-IT. Extensões próprias ficam documentadas no README como tal.
5. Nunca incluas dados reais (nomes, números de telefone, PIN/PUK, IPs) em testes, seeders ou capturas de ecrã.

---

Suggestions and fixes are welcome. Open an issue before large pull requests, keep the code style (no code comments, run `./vendor/bin/pint`), add tests under `tests/Feature` and run `php artisan test`. The API must stay Snipe-IT compatible. Never include real data (names, phone numbers, PIN/PUK, IPs) in tests, seeders or screenshots.
