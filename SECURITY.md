# Segurança / Security

## Reportar uma falha

Se encontrares uma falha de segurança, **não abras uma issue pública**. Usa a opção **Report a vulnerability** no separador **Security** deste repositório (aviso privado do GitHub). Indica:

- o que encontraste e onde (rota, ecrã ou ficheiro);
- os passos para reproduzir;
- o impacto que achas que tem.

Respondo assim que puder. Depois de corrigida, a falha pode ser descrita publicamente, com crédito a quem a reportou, se quiser.

## Reporting a vulnerability

Please **do not open a public issue**. Use **Report a vulnerability** under this repository's **Security** tab (GitHub private advisory) and include what you found, how to reproduce it and the impact. Once fixed, the issue can be disclosed publicly, with credit if you want it.

## Versões suportadas / Supported versions

Só a versão mais recente do ramo `main` recebe correções.
Only the latest version on the `main` branch receives fixes.
